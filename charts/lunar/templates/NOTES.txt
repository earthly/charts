Warning — multi-option connection string:
{{- range $stringOptions }}
  {{ . }}
{{- end }}

  Written as a string, that value reaches every consumer unchanged. The hub,
  the migrate Job and the operator read it as libpq keyword/value pairs, where
  options separate on a space; the SQL API and the Grafana datasource receive
  it as the query of a postgres:// URL, where they separate on "&". A single
  option is valid both ways. A second one is valid in exactly one, so the
  others are configured with a value they cannot parse — silently.

  Write a map and the chart renders each consumer's syntax for you:

    hub:
      db:
        connectionOptions:
          sslmode: require
          connect_timeout: 10

  Strings are accepted for the rest of chart 3.x and removed in 4.0.0.
