ACTION REQUIRED — this release installed no dashboards.

grafana.provisioning.runner is "out-of-band", so the chart rendered no
provisioning Job. Run the tool yourself from somewhere that can reach the Hub
and your Grafana ({{ .Values.grafana.url }}). Those two are all it
contacts: the Grafana credentials and the read-only database connection both
come from the Hub over gRPC.

  # ghcr.io/earthly/lunar-dashboards is private — authenticate first:
  #   docker login ghcr.io

  export LUNAR_HUB_TOKEN=$(kubectl -n {{ .Release.Namespace }} get secret \
    {{ include "lunar.hubAuthSecretName" . }} \
    -o jsonpath='{.data.{{ .Values.hub.auth.secretKey }}}' | base64 -d)

  docker run --rm \
    -e LUNAR_HUB_HOST={{ .Values.hub.ingress.api.host | default "<hub host reachable from here>" }} \
    -e LUNAR_HUB_TOKEN \
    {{ include "lunar.provisioningImage" . }}

Re-run it after every Lunar upgrade: the dashboards are versioned against the
Hub image and nothing re-applies them for you in this mode. Re-running is the
update mechanism — every step is idempotent.
{{- end }}
